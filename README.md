# Pixel Pantry

Pixel Pantry is a cozy mini cooking game where players build dishes from a pantry full of ingredients. Each round shows a recipe, and the player must match the correct ingredients in the cooking area before pressing Cook.

## Project Overview

The game is designed for a GitHub issue-based coding event. Players solve a small bug in a beginner-friendly kitchen challenge and submit a pull request for review.

The interface is a warm, playful kitchen scene with a recipe card, ingredient shelf, and cooking station. The game keeps the experience simple and fun while still covering score tracking, streaks, recipe validation, and round resets.

## Features

- Recipe card showing the current dish and the ingredients required
- Ingredient shelf with clickable items
- Cooking area where selected ingredients are assembled
- Remove ingredients from the cooking area before cooking
- Cook button to validate the current selection
- Score counter and streak tracking
- Next Recipe button to advance to a new dish
- Reset button to clear the current round
- Success and failure feedback with simple visual cues

## How to Play

1. Read the current recipe card.
2. Choose ingredients from the shelf to match the recipe.
3. Remove anything you don’t want to use.
4. Click Cook to check your dish.
5. Earn points for correct recipes and build a streak.
6. Click Next Recipe to continue to a new challenge.
7. Use Reset to clear the current round.

## Run Locally

Open `index.html` directly in your browser.

If you prefer a local web server, run:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
